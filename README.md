# Чат

Текстовый чат WhatsApp или Telegram через GREEN-API. После входа по данным инстанса можно создать диалог по номеру телефона, отправить сообщение и получать входящие. Список чатов сворачивается до аватарок, тема переключается между светлой и тёмной.

В кабинете нет тарифа MAX: создайте бесплатный инстанс WhatsApp Developer или Telegram Developer. Нужен Node.js 20+.

```bash
nvm use
npm install
npm run dev
```

Адрес будет в терминале, по умолчанию http://localhost:5173.

На экране входа выберите мессенджер и укажите `apiUrl`, `idInstance` и `apiTokenInstance` авторизованного инстанса из [личного кабинета](https://console.green-api.com). Если входящие по HTTP API выключены, приложение один раз включит их через `setSettings`: инстанс перезапустится, это может занять до 5 минут.
